# electric-tagil — Модульная архитектура проекта

Проект структурирован с четким разделением ответственности: **HTML-страницы**, **CSS-дизайн**, **конфигурации**, **чистые бизнес-функции** и **DOM-обработчики событий** вынесены в отдельные папки и файлы.

## Структура директорий

```text
electric-tagil/
├── index.html                          # Главная страница (объединяет все секции)
├── README.md                           # Документация по архитектуре проекта
├── pages/                              # Отдельные HTML-страницы разделов сайта
│   ├── calculator.html                 # Страница калькулятора сметы
│   ├── prices.html                     # Страница прайс-листа с фильтрацией
│   └── geography.html                  # Страница географии выезда (радиус 80 км)
└── assets/
    ├── css/                            # Дизайн и таблицы стилей (отдельно от разметки)
    │   ├── variables.css               # CSS-переменные, цветовая палитра
    │   ├── main.css                    # Стили сетки, фоновых паттернов и скроллбара
    │   └── components.css              # Стили UI-элементов (карточки, ползунки, модалки)
    └── js/
        ├── main.js                     # Точка входа (инициализация всех обработчиков)
        ├── config/                     # Конфигурация и справочники данных
        │   ├── tailwind.config.js      # Настройка темы и цветов Tailwind CSS
        │   └── constants.js            # Тарифы, города выезда и позиции прайс-листа
        ├── functions/                  # Чистые функции (отдельный файл на каждую задачу)
        │   ├── calculateEstimate.js    # Функция расчета итоговой сметы по площади и опциям
        │   ├── formatPrice.js          # Функция форматирования чисел и цен в рубли
        │   ├── cityService.js          # Функции сохранения и получения данных по городу
        │   ├── renderPrices.js         # Функция генерации HTML-строк прайса по категории
        │   └── validateForm.js         # Функция проверки полей формы вызова мастера
        └── handlers/                   # Обработчики событий DOM (отдельно от бизнес-логики)
            ├── calculatorHandler.js    # Обработчик кликов, ползунка и чекбоксов калькулятора
            ├── cityHandler.js          # Обработчик смены города в шапке и плашках географии
            ├── navigationHandler.js    # Обработчик мобильного меню и фильтров прайс-листа
            └── modalHandler.js         # Обработчик модального окна заявки и отправки формы
```
